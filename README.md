# homebrew-ldev

Homebrew tap for `ldev`, a local development environment manager with Traefik
routing, port reservations, REST, CLI, and MCP controls.

## Install

```bash
brew tap auhanson/ldev https://git.hnsn.dev/auhanson/homebrew-ldev.git
brew install ldev
```

## Update

```bash
brew update
brew upgrade ldev
```
